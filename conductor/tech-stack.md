# Technology Stack - AWS Cert Trainer

## Core Technologies
- **Language:** TypeScript (^6.0.3 for backend, ~5.9.2 for frontend)
- **Runtime:** Node.js

## Frontend
- **Framework:** Angular (^21.2.0)
- **UI Components:** PrimeNG (^21.1.6)
- **CSS Utility:** PrimeFlex (^4.0.0)
- **Icons:** PrimeIcons (^7.0.0)
- **State Management:** RxJS (~7.8.0)

## Backend
- **Framework:** NestJS (^11.1.19)
- **HTTP Server:** Express (^5.2.1)
- **Validation:** class-validator (^0.15.1), class-transformer (^0.5.1)
- **File Handling:** Multer (^2.1.1)

## Data Storage
- **Database:** SQLite
- **Persistence Layer:** Custom repositories with raw/file-based access.

## Development Tools
- **Build System:** npm scripts
- **Linting/Formatting:** Prettier (^3.8.1)
